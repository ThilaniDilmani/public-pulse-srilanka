# Phase 10 — Faithfulness Verification Documentation

This document describes the design, 3-stage verification architecture, atomic claim model, 4-class label taxonomy, rule checkers, metrics, human gold standard evaluation protocol, and controlled baseline experiment for Phase 10 in Public Pulse.

---

## 1. Overview & Verification Principle

Phase 10 evaluates whether natural language claims generated by the Phase 9 Grounded LLM are entailable strictly from Phase 8 retrieved evidence.

```
[GeneratedInsight] + [EvidencePayload]
                 │
                 ▼
       [ClaimDecomposer] (Decomposes Findings into atomic claims F1-C1, F1-C2)
                 │
                 ▼
       [FaithfulnessVerifier] (ZERO DB Access)
                 │
                 ├─► Stage 1: Deterministic Rules (Citations, Overgeneralization, Numbers, Quantifiers)
                 ├─► Stage 2: Lexical Overlap (Supporting signal only)
                 └─► Stage 3: Semantic Entailment Engine (LLM-as-judge for Sinhala/English NLI)
                 │
                 ▼
       [VerificationReport] (CSR, PSR, UCR, CR, Grounding Score G)
                 │
                 ▼
       [VerificationService / Repository] ──► [verification_results DB Table]
```

> [!IMPORTANT]
> **Strict Architectural Rules:**
> - **Zero Database Access in Verifier:** `FaithfulnessVerifier` receives typed dataclasses (`GeneratedInsight` + `EvidencePayload`) with **zero SQLAlchemy or DB queries**.
> - **Primary Metrics:** Claim Support Rate (CSR), Partial Support Rate (PSR), Unsupported Claim Rate (UCR), Contradiction Rate (CR), and Citation Precision. $G = \text{CSR} + 0.5 \times \text{PSR}$ is documented as a project-defined secondary heuristic.
> - **Offline Unit Testing:** `MockLLMProvider` enables 100% offline, zero-network test execution.

## 2. Atomic Claim Model & Label Taxonomy

### Atomic Claim Fields
Every evaluated claim produces a `ClaimVerification` record containing:
- `claim_id`: Stable identifier (e.g. `"F1-C1"`, `"F1-C2"`, `"F2-C1"`)
- `finding_id`: Associated finding ID (e.g. `"F1"`)
- `claim_text`: The atomic clause text evaluated
- `label`: Exactly one of `SUPPORTED`, `PARTIALLY_SUPPORTED`, `UNSUPPORTED`, `CONTRADICTED`
- `evidence_ids`: List of valid supporting evidence UUIDs
- `verification_method`: `"rule_citation"` | `"rule_overgeneralization"` | `"rule_numerical"` | `"rule_quantifier"` | `"llm_nli"`
- `reason`: Explanatory justification

### 4-Class Label Taxonomy
1. **`SUPPORTED`**: Evidence text directly entails the claim without extrapolation.
2. **`PARTIALLY_SUPPORTED`**: Main predicate supported, but minor non-vital details lack explicit evidence.
3. **`UNSUPPORTED`**: Evidence text does not contain enough information to entail the claim, or cited evidence IDs are missing/invalid.
4. **`CONTRADICTED`**: Evidence text or metadata directly contradicts the claim.

---

## 3. 3-Stage Verification Engine

### Stage 1: Deterministic Rules (`checker.py`)
- **Citation Integrity:** Empty `evidence_ids` or IDs outside `EvidencePayload` $\rightarrow$ `UNSUPPORTED`.
- **Overgeneralization:** Unbounded population claims (*"Sri Lankans believe..."*, *"The public demands..."*, *"Everyone agrees..."*) $\rightarrow$ `UNSUPPORTED` unless explicitly qualified to the sample.
- **Numerical Claims:** Compares percentages (e.g. *"60% of comments"*) against actual payload metadata ratios.
- **Quantifier Policy:** Heuristic interpretations for `majority/most` ($\ge 50\%$), `minority/few` ($< 50\%$), `approximately half` ($40\%-60\%$), `all` ($\ge 95\%$).

### Stage 2: Lexical Overlap Signal
- Jaccard similarity is evaluated as a supporting signal only. It **MUST NOT** independently classify a claim as `SUPPORTED`.

### Stage 3: Multilingual Semantic NLI (`verifier.py`)
- Evaluates Sinhala script, Singlish, English, and code-mixed text using the `LLMProvider` abstraction (`GeminiProvider` / `MockLLMProvider`) with an NLI prompt.

---

## 4. Evaluation Metrics

- **Claim Support Rate (CSR):** $\frac{\text{SUPPORTED}}{\text{Total Claims}}$
- **Partial Support Rate (PSR):** $\frac{\text{PARTIALLY\_SUPPORTED}}{\text{Total Claims}}$
- **Unsupported Claim Rate (UCR):** $\frac{\text{UNSUPPORTED}}{\text{Total Claims}}$
- **Contradiction Rate (CR):** $\frac{\text{CONTRADICTED}}{\text{Total Claims}}$
- **Secondary Grounding Score ($G$):** $G = \text{CSR} + 0.5 \times \text{PSR}$
- **Evidence Citation Precision:** $\frac{\text{Valid Cited Evidence IDs}}{\text{Total Cited Evidence IDs}}$

---

## 5. Human Gold Standard Protocol

- **Sample:** 100 stratified `GeneratedInsight` outputs across Sinhala, English, Singlish, code-mixed text, programs, topics, and stance patterns.
- **Annotators:** 3 independent bilingual Sinhala/English annotators labeling atomic claims into the 4-class taxonomy.
- **Inter-Rater Reliability:** Measured using Fleiss' Kappa ($\kappa$). Target: $\kappa \ge 0.70$.
- **Adjudication:** Majority vote; ties resolved by lead researcher.
- **Verifier Benchmark:** Compute Accuracy, Precision, Recall, and F1-score of Phase 10 automated verifier vs Human Gold Standard.

---

## 6. Controlled Research Baseline Experiment

- **Baseline:** Topic Question $\rightarrow$ Un-grounded LLM (Zero evidence provided).
- **System:** Topic Question $\rightarrow$ Phase 8 Evidence $\rightarrow$ Phase 9 Grounded LLM.
- **Comparison:** CSR, PSR, UCR, CR evaluated under identical verifier configurations. Statistical significance evaluated via Two-sample Z-test for proportions ($p < 0.01$).
